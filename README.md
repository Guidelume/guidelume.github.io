# Guidelume
## Breaking through the gloom, a solitary light that helps people to mod their games.
### Created by Varkorax

That is a very fancy way of saying that I create guides to help people mod their games, primarily old BioWare right now.
Guidelume is the official umbrella for these projects, present and future, bringing them together under one roof for the sake of maintainability.
