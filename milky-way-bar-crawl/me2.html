Installation

Who say the journey can't be just as enjoyable as the destination? Here’s the secret to a good bar crawl:

  1. Open M3.
  2. Select Mod Management → Batch Mod Installer.
  3. Load the batch file:
    • If you downloaded the list through M3, it will appear automatically.
    • If you downloaded it manually, place the file into: (Your M3 folder)/mods/BatchModQueues
      Then reopen the Batch Mod Installer.

  4. Download every mod through the Batch Mod Installer whenever possible. This ensures you get the correct versions of everything.
    In cases where it is not possible to go through the Installer, simply download and import manually.
    Depending on your Nexus membership and file sizes, this may take a little while. Please be patient with your aging barman (28).
  5. Once everything has finished downloading, click Install this group.
  6. When asked if you want to use previously saved options, click Yes.
  7. Wait until everything is installed, then launch the game once to make sure everything is working.
  8. Congratulations! You've survived the easy part. Before you start playing, head on over to Finish.

Patches / Compatibility

If you were to install the mods listed below from top to bottom, all relevant patches should appear when needed.
Remember that you are shaping your own flavor of drink here however, so be sure to always read thoroughly through each mod's Nexus page.



Unofficial LE2 Patch

By: Marcus22Khaar and Team Pyjak
If you are only ever going to install a single mod, pick this one.
Bugfix mods are always a bit unglamorous by nature, but the work the community has put into these ever since the ME2Recalibrated days is beyond astonishing.
Note: This mod is foundational and required by basically every other mod on this list.

Myriad Pro Begone

By: Audemus
Replaces the font used throughout the game with something more fitting for the setting.
Note: The file contains versions for every game plus the Launcher. You may import everything or just the LE2 version.

LE2 Prologue Framework

By: beccatoria
This game is so borked you need a framework mod to safely edit the prologue.

Genesis Begone

By: Marcus22Khaar
Genesis is an official DLC that attempts to onboard players who skipped ME1 by editing the prologue and adding an interactive comic that recaps the story. In the process, it also makes some rather clumsy changes to the opening. This mod puts everything back where it belongs.
Note 1: This mod requires LE2 Prologue Framework and Unofficial LE2 Patch.
Note 2: If you're curious about the interactive comic, you can leave the prompt to view it intact.
