Appendices - Common Questions

"A mod updated. Should I install the update?"

▾

Usually no - at least not in the middle of a playthrough.
Unless the update specifically fixes a problem you're experiencing, it's generally safest to finish your current run first. Updating content mods mid-playthrough can occasionally introduce new issues or incompatibilities.
If you're starting a new playthrough, updating is usually a good idea.

"Can I add more mods later?"

▾

Absolutely.
As long as you haven't started installing texture mods yet, you can keep expanding your setup whenever you like.

"M3 says my game is texture modded."

▾

If you texture modded your game, that's expected.
It's a safety feature of M3 to protect your game from corruption.
If you need to install additional content mods, you'll need to restore a clean backup or reinstall the game.

"A mod disappeared from Nexus!"

▾

It happens from time to time.
Authors sometimes hide, replace, or remove their work.
If that affects this guide I'll either replace the recommendation or update the list during the next maintenance pass.

"Where should I ask for help?"

▾

If you've run into trouble:

  1. Read the mod's description page.
  2. Check the comments section on Nexus.
  3. Check this guide to make sure nothing was skipped.
  4. If you're still stuck, feel free to contact me.

"The guide recommends a mod I don't like."

▾

That's perfectly fine.
This is a curated guide, not the only correct way to mod Mass Effect.
Skip anything that doesn't appeal to you - just keep an eye on any dependencies or compatibility notes.
