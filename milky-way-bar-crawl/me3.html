Installation

Who say the journey can't be just as enjoyable as the destination? Here’s the secret to a good bar crawl:

  1. Open M3.
  2. Select Mod Management → Batch Mod Installer.
  3. Load the batch file:
    • If you downloaded the list through M3, it will appear automatically.
    • If you downloaded it manually, place the file into: (Your M3 folder)/mods/BatchModQueues
      Then reopen the Batch Mod Installer.

  4. Download every mod through the Batch Mod Installer whenever possible. This ensures you get the correct versions of everything.
    In cases where it is not possible to go through the Installer, simply download and import manually.
    Depending on your Nexus membership and file sizes, this may take a little while. Please be patient with your aging barman (28).
  5. Once everything has finished downloading, click Install this group.
  6. When asked if you want to use previously saved options, click Yes.
  7. Wait until everything is installed, then launch the game once to make sure everything is working.
  8. Congratulations! You've survived the easy part. Before you start playing, head on over to Finish.

*

After installation is complete the Expanded Galaxy Mod Settings utility will open itself.
Navigate to the Mission Timings tab and for the Citadel DLC switch to Disable DLC (or CEM Full).
You need to do this since the list includes Citadel Epilogue Mod (CEM), which turns that DLC into an Epilogue for the game.
If you do not change this you'll be able to start the DLC like normal, which defeats the purpose of CEM a bit.

Patches / Compatibility

If you were to install the mods listed below from top to bottom, all relevant patches should appear when needed.
Remember that you are shaping your own flavor of drink here however, so be sure to always read thoroughly through each mod's Nexus page.



LE3 Community Patch

By: Kinkojiro and the LE3 Community Patch Team
If you are only ever going to install a single mod, pick this one.
Bugfix mods are always a bit unglamorous by nature, but the work the community has put into these ever since the ME3Recalibrated days is beyond astonishing.
Note: This mod is foundational and required by basically every other mod on this list.

Myriad Pro Begone

By: Audemus
Replaces the font used throughout the game with something more fitting for the setting.
Note: The file you download has a version for every game plus the Launcher. You may import everything if you want or just choose the LE3 version.

Journal Enhanced

By: 55tumbl
Various QoL enhancements for the journal, such as showing when a mission cannot be done yet or is ready to be turned in.

Permanent CIC Hologram

By: Herobrine24
Makes the holograms in the CIC persistent regardless of where you are.
Note: The file contains both the LE2 and LE3 version. You can import both or just the LE3 version.

F.I.S.H.

By: beccatoria
Traynor will now feed your fish without needing to romance her. Kelly will also return your fish to you regardless of whether you flirted with her during LE2.
Funnily enough there is a fish feeder in the game you can buy, but it's stupid expensive and doesn't unlock for a while if memory serves.

Diana Allers Overhaul

By: MentalHygiene
Visual overhaul for Allers, plus a few new outfit choices for her.
Note: If you plan on following the Textures section later this mod is a soft requirement.

Fate of Emily Wong LE3

By: matallic
Emily Wong was killed off in a promotional Twitter gimmick account storyline in the leadup to ME3. This mod adds those tweets as an Email you get from Allers.

Reegar Lives

Apartment Additions

Adds a lot of new decorations for you to purchase for your Citadel DLC apartment.

Pinnacle Station Apartment

Bonus: Explaining Choices

▾

Some visitors have asked me, "Barman, why did you choose X? Why not Y?"
While I won't bore you with justifying every single decision, there are a few big ones where I'll indulge you.



LE3 Diversification Project over Project Variety

Both mods do broadly the same thing: they expand the universe of LE3. So why did I choose LE3DP?

The short version is that I prefer its implementation. Some of the additions in Project Variety don't feel quite as polished or well-integrated to me, and I'm not particularly interested in its cosmetic additions, such as all the extra outfits.

More importantly, perhaps, LE3DP better fits what I'm trying to accomplish with this guide. Despite the sheer amount of content it adds, I find it tends to feel more like Vanilla+ (or at least closer to that philosophy) than PV does. That is admittedly a very subjective assessment, and I'm sure someone else could play both and come away with the exact opposite impression.

In summary, this isn't really a case of "LE3DP good, PV bad." Project Variety is a really fun beast of a mod. I simply prefer what LE3DP does, and I think it fits the overall direction of this guide better.
